# 汽车上市公司财报问答知识库

人工智能课程作业，方向A：财报问答知识库。

基于10家A股汽车上市公司2025年年度报告，支持单公司和多公司财务指标查询，回答附公司、文件、页码和章节信息。

## 数据范围

比亚迪、上汽、长城、长安、广汽、北汽蓝谷、江淮、赛力斯、宇通客车和中通客车。

原始财报PDF未上传仓库。运行前需准备对应2025年年度报告，并放入项目根目录的 `reports` 文件夹，命名为：

```text
北汽蓝谷25.pdf
比亚迪25.pdf
广汽25.pdf
江淮25.pdf
赛力斯25.pdf
上汽25.pdf
宇通25.pdf
长安25.pdf
长城25.pdf
中通25.pdf
```

解析数据和索引由下述程序在本地生成，仓库中的代码不能在缺少这些数据时直接启动问答。

## 实现方法

1. 逐页提取PDF正文和表格，记录公司、来源文件、页码和章节。
2. 正文按800字符切块，相邻块重叠150字符；表格单独保留为文本块。
3. 建立BM25和TF-IDF索引，使用加权得分进行混合检索。
4. 对营业收入、研发投入、归母净利润、经营活动现金流净额，增加公司内全表扫描，优先选择年度整体口径，并回查单位。
5. 多公司问题分别查询每家公司，再汇总答案和出处。
6. 通过Streamlit提供网页问答界面。

TF-IDF使用词项稀疏向量，不是语义嵌入模型。当前回答主要采用规则提取，没有接入大语言模型生成接口。

## 安装与运行

需要Python环境。在项目目录的终端执行：

```powershell
python -m pip install pdfplumber numpy jieba rank-bm25 scikit-learn joblib streamlit
```

准备好 `reports` 中的10份PDF后，依次执行：

```powershell
python extract_reports.py
python build_chunks.py
python build_index.py
python -m streamlit run app.py
```

三个数据处理程序依次生成 `processed` 和 `index` 中的文件。重新执行会更新相应生成文件。

网页启动后，打开终端显示的本地地址。

## 示例问题

- 比亚迪2025年营业收入是多少？
- 比亚迪2025年研发投入是多少？
- 比亚迪和长城汽车2025年的研发投入分别是多少？

## 项目文件

| 文件 | 用途 |
|---|---|
| `extract_reports.py` | 提取PDF正文、表格和页级信息 |
| `build_chunks.py` | 构建正文及表格文本块 |
| `build_index.py` | 构建BM25和TF-IDF索引 |
| `search_test.py` | 查看混合检索结果及得分 |
| `qa_engine.py` | 指标识别、证据选择及回答 |
| `app.py` | 网页问答界面 |
| `test_questions.json` | 10道测试题，含2道跨公司题 |
| `run_tests.py` | 批量运行测试并保存记录 |

## 测试记录

准备好数据与索引后执行：

```powershell
python run_tests.py
```

新记录保存在 `results/test_results.txt`。

本仓库已上传的测试材料位于根目录：

- [10题正式运行记录](test_results.txt)：问题、回答、出处和后台召回记录。
- [10题逐题评估](test_evaluation.md)：金额核对结果及错误或不足。

当前10道固定测试题所问的2025年金额及公司对应关系均与本地对应解析页一致。这不代表任意问题都能正确回答，也不代表混合检索的召回率达到100%。

## 实验发现与不足

标准财务指标中，全表扫描及年度口径优先规则能够补足混合检索的召回遗漏。例如，比亚迪年度营业收入可以定位到主要会计数据表，避免误选营业外收入或季度收入。

仍存在以下不足：

- 部分章节名称识别不准确，沿用了此前标题。
- 混合检索前5条结果不一定包含最终答案出处；最终出处与后台召回记录来自不同通道。
- 复杂表头、调整前后列以及没有百分号的同比数据尚未完整处理。
- 测试主要覆盖标准金额指标，尚未充分验证开放性问题和自由问法。

逐题评估由助手辅助核对，核对依据为本地解析正文和表格，未在该评估中重新逐页目视检查全部原始PDF。
